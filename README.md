# M5 Ultra benchmark replication runbook

A standalone guide for benchmarking oMLX with GLM-5.3-Flash-oQ4e and comparing 256GB versus 512GB usefulness.

## Open locally

Open `index.html` in any web browser. No installation, build step, or internet connection is required to read the guide. Source links require internet access.

## Files

- `index.html`: complete page, including styling, print controls, and an embedded Markdown download.
- `m5-ultra-replication-runbook.md`: editable Markdown version.
- `README.md`: these instructions.

This package is a runbook, not a benchmark application. Follow its prerequisites and commands on the Mac being tested. The earlier synthetic quality-test corpus is not included; the runbook identifies that dependency.
